## 🎯 Propósito del Proyecto

**SmartAcademy** es una aplicación móvil nativa multiplataforma diseñada para centralizar y agilizar la administración de instituciones y academias educativas, conectando directivos, docentes y estudiantes en una experiencia móvil fluida.

## 📱 Módulos Principales

- **Gestión de Estudiantes y Matrículas:** Registro, perfiles académicos y estado de inscripción.
- **Control de Horarios y Asistencia:** Seguimiento diario por curso, docente y aula.
- **Seguimiento de Calificaciones:** Consulta en tiempo real de desempeño y reportes académicos.
- **Diseño UI Moderno en Flutter:** Componentes reutilizables, navegación intuitiva y alto rendimiento nativo.

## 🚀 Ejecución Local

```bash
git clone https://github.com/campodidier07-collab/SmartAcademy.git
cd SmartAcademy
flutter pub get
flutter run
```
